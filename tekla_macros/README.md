# Desktop Controller - Tekla 深化宏示例

本目录包含针对具体项目的 Tekla 参数化深化宏示例。

## 天浩电器1#生产车间

文件：`天浩电器1厂房_一键深化.vbs`

### 项目参数（从图纸提取）

| 参数 | 值 |
|------|-----|
| 结构形式 | 门式刚架轻型房屋钢结构 |
| 跨度方向柱距 | 5700/5000/5850/5850/5000/5700 mm |
| 总跨度 | 33100 mm |
| 柱高 | 8000/8590/9090/9670/9090/8590/8000 mm |
| 刚架柱截面 | 变截面 I(300-500)*250*6*12 |
| 抗风柱截面 | 等截面 I300*250*6*12 |
| 屋面梁截面 | I400*180*6*10 |
| 材质 | Q355B |
| 屋面坡度 | 1:10 (10%) |

### 生成内容

1. 轴网（X向7柱 + Y向多榀 + Z向标高）
2. 钢柱（变截面刚架柱 + 等截面抗风柱）
3. 屋面梁（沿柱顶折线布置）
4. 柱间交叉支撑
5. 屋面水平支撑
6. 檩条（按间距沿屋面布置）
7. 柱顶系杆

### 使用方法

1. 打开 Tekla Structures
2. 新建或打开模型
3. 工具 → 宏 → 运行 → 选择 `.vbs` 文件
4. 或放入宏目录后从宏列表运行

### 注意事项

- 变截面柱的 ProfileString 格式需根据 Tekla 截面库调整
- 纵向榀数和间距需根据结构平面布置图确认
- 节点/连接需后续手动或用组件添加
- 运行前建议先在空白模型测试
